# 🤝 Contributing to SmartyAI

Thank you for considering contributing to SmartyAI! We welcome all developers.

## How to Contribute
1. Fork the repository.
2. Create a new branch: `git checkout -b feature/your-feature-name`.
3. Make your changes and test them locally.
4. Submit a Pull Request (PR) with a clear description of your changes.

## Development Setup
Follow the [Installation Guide](#-installation--run-guide) in the README to set up your local environment.

## Code Style
- Use ESLint and Prettier for formatting.
- Write clear, commented, and maintainable code.

## Reporting Issues
Please use the [Issues](https://github.com/smarty7app/Smarty/issues) tab to report bugs or suggest features.
