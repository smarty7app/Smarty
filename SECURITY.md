# 🔒 Security Policy

At **SmartyAI**, we take security seriously. We are committed to protecting our users' data, payment information, and API credentials.

## Supported Versions

Currently, only the latest beta version is actively supported with security updates.

| Version | Supported |
| :--- | :--- |
| **0.1.x (Beta)** | ✅ Supported |
| < 0.1.0 | ❌ Not Supported |

> ⚠️ **Note**: As SmartyAI is currently in beta, we recommend all users to update to the latest release to ensure they have the most recent security patches.

---

## Reporting a Vulnerability

If you discover a security vulnerability in SmartyAI, please **do not** disclose it publicly. Instead, report it directly to us.

### 📬 How to Report
1. **Private Disclosure**: Send an email to [smarty@smartyai.net] with the subject line: `[SECURITY] SmartyAI Vulnerability Report`.
2. **Alternative**: Open a **private issue** on GitHub (if available) or contact us via the repository's issue tracker with the `security` label (for non-sensitive issues).

### 🔍 What to Include
To help us investigate and fix the issue quickly, please provide:
- A clear description of the vulnerability.
- Steps to reproduce the issue (including screenshots or code snippets if possible).
- The version of SmartyAI you are using.
- Any potential impact or exploit scenarios you have identified.

### ⏱️ Response Timeline
| Phase | Expected Time |
| :--- | :--- |
| **Initial Acknowledgment** | Within 24-48 hours |
| **Status Update** | Within 5-7 business days |
| **Fix Release (if critical)** | Within 10-14 business days |

### ✅ What to Expect
- If the vulnerability is **accepted**, we will:
  - Work on a fix and release a patch as soon as possible.
  - Credit you in the release notes (if you wish).
- If the vulnerability is **declined**, we will provide a clear explanation of our decision.

We appreciate your help in keeping SmartyAI secure for everyone. Thank you for contributing to the safety of the Algerian e-commerce ecosystem! 🇩🇿

## 🔐 Security Best Practices (for Users)

To ensure your account and data remain secure, we recommend:
- **Never share your `GEMINI_API_KEY`, `CHARGILY_SECRET_KEY`, or Firebase configuration files** publicly.
- Regularly update to the latest version of SmartyAI.
- Use strong, unique passwords for your admin accounts.
- Enable two-factor authentication (2FA) on your Firebase authentication providers.
- Review your Firestore security rules periodically to ensure they align with your business needs.

---

## 📝 Responsible Disclosure

We follow a **responsible disclosure** policy:
- We will keep you informed throughout the process.
- We will not pursue legal action against researchers who act in good faith and follow this policy.
- Public disclosure will only occur after the issue has been resolved and a patch has been released.
